# 단축키 편집 기본값 회귀표 (2026-11-12)

## 증거 범위

아래 **변경 전** 열은 `MpvPlayer.cs`, `MainWindow.Playback.cs`, `MainWindow.xaml.cs`, `SettingsWindow.xaml.cs`, `RemoteWindow.xaml.cs`의 소스를 읽어 작성한 기준이다. 초기 소스 기준이며, 아래 실행 결과 표에 실제 게스트 관측을 별도로 기록했다. **변경 후**의 '소스 동일'은 통합된 기본 키 표·실행 경로의 소스 대조 결과이며 실제 키 입력 통과를 의미하지 않는다. GUI·키·마우스 검증은 Hyper-V 게스트에서만 수행한다. 호스트 입력 주입은 하지 않는다.

관리 대상은 기능 22개, 기본 키 23개다. 전체 화면의 `f`, `F11`은 같은 기능의 별칭이다. mpv 내장 기본 키 전체를 앱의 편집 가능 키로 확대하지 않는다. 기존 `input-default-bindings=yes`는 유지하되 앱에서 재지정한 이전 키가 mpv 내장 동작으로 되살아나지 않게 처리해야 한다.

## 문자·수정키·포커스 보존 조건

- 영어 대소문자와 CapsLock/Shift, 물리 키와 VK_PACKET 입력을 구분해 검증한다. 한글 IME의 물리 M/S/L/F는 원래 VK로 처리한다. 한글 자모 VK_PACKET `ㅡ/ㄴ/ㅣ/ㄹ`은 M/S/L/F 위치의 별칭이다. 기능을 다른 키로 옮기면 별칭도 새 키 위치를 따라야 하고 이전 글자가 이전 기능을 호출하면 안 된다.
- 기존 H는 Ctrl/Alt/Win이 있으면 처리하지 않고 Shift는 무시한다. 기존 W는 Ctrl/Alt/Win을 거부하고 Shift+Left/Right만 긴 탐색으로 분기하며 나머지는 Shift를 무시한다. A에 등록한 키 문자열은 기존 그대로 유지한다. 편집한 키의 수정키는 정확하게 적용한다.
- H는 앱 최상위 창이 전경이고 엔진 A이며 mpv가 있을 때만 동작한다. 처리한 KeyUp도 소비하고 키 반복 상태를 추적한다. 설정 창 등 다른 창이 전경이면 처리하지 않는다.
- TextBoxBase, ComboBox, ListBox/Item, 별도 PresentationSource(메뉴·팝업)에 포커스가 있으면 W/H는 처리하지 않는다. W의 버튼 Space는 기존 버튼 클릭을 유지한다. 엔진 B에서는 새 단축키를 처리하지 않는다.
- Escape는 설정 창 닫기·리모컨 뒤로·목록 패널 닫기와 충돌시키지 않는다. 새 편집 UI의 키 입력은 재생 동작으로 새지 않아야 한다.

## 통합 설계와 편집 회귀

- 기능 ID, 표시 이름, 기본 키 목록, 반복 정책, 허용 경로를 단일 표에서 정의한다. native 등록, WPF 조회, H 문자/VK 조회, 설정 표시가 이 표를 참조한다. `RunKeyAction`의 기존 기능 실행은 보존한다.
- `%LOCALAPPDATA%\\HybridPipPlayer\\shortcuts.json`에는 기본값과 다른 기능의 키 배열만 저장한다. 빈 배열은 명시적 비활성화다. 기본값 복원은 해당 override를 제거하고 전체 복원은 빈 overrides를 저장한다.
- 전체 후보 맵을 검사한 뒤 한 번에 적용한다. 동일 키, 같은 기능 안 중복 별칭, 기본 Shift 허용으로 생기는 유효 충돌, 7개 예약 전역 키를 검출한다. 오류가 있으면 기존 메모리·파일·native 바인딩을 바꾸지 않는다.
- 저장 실패를 표시하고 기존 설정을 유지한다. 임시 파일을 작성한 뒤 교체해 중간 쓰기로 인한 손상을 줄인다. 잘못된 JSON, 모르는 ID, 잘못된 키, 과도한 크기는 시작 실패로 이어지지 않게 거절한다.
- 적용 시 관리 대상 기본 키를 native `ignore`로 비운 다음 새 키를 바인딩한다. 새로 사용한 비기본 키는 최초 덮어쓰기 직전 `input-bindings`의 가장 높은 활성 priority 명령을 보관하고, 해제·복원 때 되돌려 재시작 전후를 일치시킨다. 별도 과거 이력은 저장하지 않는다. 앱이 관리하지 않는 mpv 기본 키는 그대로 두며, 저장 이후 외부 스크립트가 동적으로 변경한 바인딩까지 추적하지는 않는다.
- 기존 훅이 소비하던 기본 문자의 Shift 형태도 해제 후 계속 소비한다. 예를 들어 `[`를 바꿨을 때 Shift+`[`가 mpv 내장 `{` 배속 명령으로 되살아나지 않게 한다. 새로운 native Shift 바인딩을 추가하는 방식은 사용하지 않는다.
- 변경·비활성화·저장·재시작·한 기능 복원·전체 복원, 전체 화면 두 별칭 독립 편집, 충돌과 저장 실패, 기존 포커스 차단을 검증한다. 테스트 파일은 격리 경로를 사용해 호스트 사용자 설정을 변경하지 않는다.
